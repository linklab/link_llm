# link_llm — 나만의 작은 언어 모델 (v0.0.6)

누구나 쉽게 이해할 수 있는 **아주 기본적인** 언어 모델(LMM)이에요.
어려운 신경망(딥러닝) 없이, **"토큰을 세는 것"** 으로 문장을 만들어 봅니다.

## v0.0.5 → v0.0.6, 무엇이 바뀌었나요?

> **토크나이저(문장을 토막 내는 규칙)를 똑똑하게 바꿨어요.**
> (백오프 + 확률/온도(v0.0.5)는 그대로 유지해요.)

- v0.0.5 까지는 **띄어쓰기**로만 잘랐어요. 그래서 `"좋아!"` 가 통째로 한 덩어리라,
  `"좋아"` 와 `"좋아!"` 를 **서로 다른 단어**로 여기는 손해가 있었죠.
- v0.0.6 은 **문장부호(. , ! ?) 를 따로 떼어내서** 각각 하나의 토큰으로 만들어요.

```
"좋아!"        ->  ["좋아", "!"]
"먹고, 잤어."  ->  ["먹고", ",", "잤어", "."]
```

이렇게 하면 `"좋아"` 는 항상 같은 토큰이 되고, **문장부호가 언제 나오는지도** 배울 수 있어요.
문장을 만들 때는 문장부호를 앞 단어에 딱 붙여서 보여줘요 → `오늘 날씨가 좋습니다!`

## 저장되는 모델 형식 (v0.0.6)

`tokenizer` 와 백오프용 `tables` 를 함께 저장해요.

```json
{
  "max_order": 2,
  "tokenizer": "punct",
  "tables": {
    "2": { "오늘 날씨가": { "정말": 1, "조금": 1 }, "좋습니다 !": { "<END>": 1 } },
    "1": { "오늘": { "날씨가": 3, "기분이": 3 }, "!": { "<END>": 8 } }
  }
}
```

## 사용 방법

```bash
python3 3.train/train.py     # 1) 학습 (문장부호 분리 + 백오프용 표1, 표2)
python3 4.test/test.py       # 2) 문장을 만들어 보기 (문장부호가 자연스럽게 나옴)
```

웹앱(`web_service`)은 각 버전의 `tokenizer` 정보를 읽어 자동으로 맞는 방식으로 처리해요.

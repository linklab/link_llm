# link_llm — 나만의 작은 언어 모델 (v0.1.5)

**기준선 대결 (캡스톤).** 신경망 시대(v0.1.x)를 마무리하며,
**카운트 vs 신경망**을 같은 자(퍼플렉서티)로 나란히 재서 "신경망이 정말 이겼나?"를 확인해요.

## v0.1.4 → v0.1.5, 무엇이 바뀌었나요?

> **모델이 아니라 '비교'가 새 개념.** 모델·학습은 v0.1.4(2토큰 문맥) 그대로이고,
> 여러 버전을 **같은 학습/검증 데이터로 PPL** 재서 대결표를 뽑는 도구를 더했어요.

## 대결 방법

```bash
# (torch 환경) 비교할 신경망 버전들을 먼저 학습해 model.json 을 만들어 두고…
python3 llm/v0.1/v0.1.0/1.train/train.py
python3 llm/v0.1/v0.1.3/1.train/train.py
python3 llm/v0.1/v0.1.4/1.train/train.py    # 2토큰 문맥
python3 llm/v0.1/v0.1.5/1.train/train.py
# 대결표 출력
python3 llm/v0.1/v0.1.5/2.test/test.py
```

실제 출력 (산문 pretraining, `eval_suite.py` · 각 버전 `1.train/train.py` 기본 하이퍼파라미터):
```
버전     종류    검증PPL   top-1   후보有
v0.0.9   카운트     2.96    73.5%   97.1%   ← 개수 세기 기준선(앞 2토큰)
v0.1.0   신경망     8.44    60.7%   98.9%   ← full-batch 수동 SGD (덜 수렴)
v0.1.1   신경망     4.09    64.8%   98.9%   ← 미니배치로 훨씬 더 학습
v0.1.2   신경망     4.08    64.9%   98.9%   ← Adam
v0.1.3   신경망     4.07    64.9%   98.9%   ← 정규화·초기화 (여기까지 1토큰)
v0.1.4   신경망     3.02    73.6%   98.9%   ← 앞 2토큰(카운트와 같은 조건)
v0.1.5   신경망     3.02    73.6%   98.9%
→ 검증 PPL 최저: v0.0.9 (카운트) = 2.96
  → 신경망은 카운트 기준선(v0.0.9 2.96)을 아슬아슬하게 넘지 못했어요(2토큰 신경망 3.02). ❌
  → 1토큰 신경망(4.07~4.09)은 물론, 같은 2토큰(3.02)조차 카운트(2.96)를 못 이깁니다.
→ top-1 정확도: 카운트 73.5%  vs  2토큰 신경망 73.6% — 거의 동률
→ '정답이 후보에 있음': 카운트 97.1%  vs  신경망 98.9%
```

읽는 법 세 가지:

1. **문맥 1토큰(v0.1.0~3)은 카운트(앞 2토큰)를 못 이겨요.** (1토큰 최고 4.07 > 카운트 2.96)
   같은 2토큰으로 맞춘 v0.1.4 도 **3.02** 에 그쳐 카운트 2.96 을 아슬아슬하게 넘지 못합니다 —
   산문 pretraining 에서는 **카운트(2.96)가 여전히 최저**, 신경망이 이기지 못한다는 게 이 대결의 결론이에요.
   왜냐하면 조기 종료가 이제 **검증이 아니라 학습 손실**을 보기 때문(patience=20)에, 모델이 검증
   최적점을 지나 계속 학습해 살짝 과적합돼요 — 검증을 봤다면 일반화 최적점에서 멈췄을 거예요.
   (쉬운 산문이라 격차가 작아요. 신경망의 진짜 격차는 대화 SFT 인 **v0.5** 에서 드러납니다.)
2. **`후보有`(coverage) 97.1% vs 98.9%** 가 카운트의 근본 한계예요. 카운트는 검증 토큰의
   약 2.9% 에서 정답을 표에 아예 갖고 있지 않습니다. PPL 에서는 `FLOOR` 가 메워줘 잘 안 보이는
   차이가, 이 열에서는 그대로 드러나요.
3. **지표마다 승자가 다를 수 있어요.** 'PPL(확률을 잘 배분하는 것)'과 'top-1(1등을 잘 맞히는
   것)'은 다른 능력이라, 두 버전의 순위가 지표에 따라 뒤바뀔 수 있어요. 어느 자로 쟀는지를
   같이 말해야 합니다. (버전별 정확한 값은 `2.test/test.py` 를 직접 돌려 확인하세요.)

- **검증 PPL 이 낮을수록** '처음 보는 것'에 강한 모델이에요.
- **1토큰(v0.1.0~3) vs 2토큰(v0.1.4~5)** 을 나란히 보면 '문맥 길이'의 효과가 한눈에 보여요.
- 아직 학습 안 된 버전이나 torch 없는 신경망 버전은 자동으로 **건너뛰고** 이유를 알려줘요.

## 공정한 비교

모든 버전이 같은 토크나이저·`<END>`·`perplexity()` 공식을 쓰고, **확률 엔진(개수 표 ↔ 신경망)만** 달라요.
특히 v0.1.4~5 는 카운트와 **문맥 길이(2토큰)까지 같아** 완전한 사과 대 사과 비교예요.

## 완결성 — 웹앱에서도

`model.json` 을 `type` 으로 구분해 로드하므로, 웹앱(`web_service`)에서 v0.1.5 를 골라 **문장 완성으로도** 평가할 수 있어요.
(대결표는 `2.test/test.py`, 문장 이어쓰기는 웹앱 — 둘 다 됩니다.)

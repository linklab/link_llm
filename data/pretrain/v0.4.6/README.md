# v0.4.6 — 독립 최종 평가 문서

모델·토크나이저·학습량을 `llm/v0.4/v0.4.6/0.model/freeze.json`에 고정한 **후에** 새로 작성한 평가 전용 문서입니다.

- 도자기·지하철·종이접기·재활용·인쇄·그림자극: 6개 주제, 각각 다른 글 2개씩 총 12개.
- AI의 도움으로 직접 작성했으며 외부 코퍼스를 수집하지 않았습니다. 저장소와 같은 MIT 사용 조건입니다.
- 기존 train·valid·test와 정규화 중복, 선언된 주제·템플릿의 겹침을 검사합니다. 문장 의미나 문체까지 독립이라는 뜻은 아닙니다.
- BPE 학습·신경망 학습·모델 선택에 사용하지 않습니다. 최종 점수를 본 뒤 이 자료에 맞춰 모델을 다시 선택하지 않습니다.

`test.jsonl`은 원문을 보존한 고정 자료입니다. `manifest.json`에는 원문 파일과 모델 고정 기록의 해시를 담았습니다. 변경된 자료는 평가기가 거부합니다.

```bash
# 이미 봉인된 자료의 무결성 확인; 다시 덮어쓰지 않음
python data/pretrain/v0.4.6/seal.py
python llm/v0.4/v0.4.6/2.test/test.py
```

12개의 합성 문서이므로 광범위한 언어 능력이나 실제 서비스 품질을 대표하지 않습니다. 기존 v0.4.1 test는 과거에 이미 보고했으므로 새 독립 평가와 따로 표시합니다.

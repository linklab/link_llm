- **문맥 길이:** 앞 1 + 2단어 (백오프)
- **토크나이저:** `punct` / **문장 끝:** `<END>` / **대화:** 역할 토큰 `<사용자>`·`<봇>` (v0.0.8 그대로)

  (이후 버전들은 이 평가 함수들을 상속만 하면 돼요. 신경망은 `next_dist()` 만 softmax 로 덮어씁니다.)

## 퍼플렉서티는 어떻게 계산하나

각 토큰의 확률을 백오프로 구하고(`token_prob`), 못 찾으면 아주 작은 값(`FLOOR`)을 줘요.

```
p(token | 문맥) = 그 문맥에서 token 이 나온 횟수 / 그 문맥의 전체 횟수
PPL = exp( 평균( -log p(각 토큰) ) )      # 낮을수록 잘 맞힘
```

- 학습 데이터: 대부분 표에 있어 확률이 높음 → PPL 낮음
- 검증 데이터: 처음 보는 조합 → 백오프·FLOOR 에 의존 → PPL 높음

## 정확도는 어떻게 계산하나

`next_dist(recent)` 가 **모델이 실제로 예측을 뽑는 표**(백오프로 처음 찾은 표)를
확률 분포로 돌려주고, `accuracy()` 가 그 안에서 정답의 순위를 봅니다.

```
top1     = 1등이 정답인 비율
topk     = 정답이 상위 k개 안에 든 비율
coverage = 정답이 후보에 있기라도 한 비율
```

> ⚠️ `token_prob()` 은 "그 표에 그 토큰이 없으면 더 짧은 문맥으로 한 번 더" 찾지만,
> `next_dist()` 는 **생성(`generate`)과 같은 규칙**으로 처음 찾은 표만 봅니다.
> 그래서 PPL 이 정확도보다 조금 후하게 나와요 — 이 차이 자체가 `coverage` 로 드러납니다.

# v0.4.4 — KV 캐시

**앞에서 계산한 Key·Value를 저장해 다음 토큰 생성 때 재사용합니다.** “오늘은 → 오늘은 날씨가”처럼 문장을 한 토큰씩 이어 갈 때, 앞부분을 매번 계산하는 비용을 줄입니다.

## 정확성을 지키는 방식

- 캐시는 요청 안에서만 만들고, 다른 요청과 공유하지 않습니다. 샘플링 설정과 RNG도 요청별로 분리합니다.
- 같은 문맥의 뒤에 토큰이 붙으면 새 부분만 계산합니다. 다른 문맥으로 바뀌면 초기화합니다.
- 64토큰을 넘어서 창이 밀리면 **전체 창을 다시 계산**합니다. 학습형 위치 번호와 이전 토큰들의 표현이 달라지므로 단순히 가장 오래된 K/V만 지우면 기존 모델과 달라집니다.
- 학습은 기존 경로를 사용합니다. 캐시는 eval 모드의 한 문서만 받으며 PAD·다른 모델의 캐시는 거부합니다.

## 검증·실측

v0.4.3의 가중치를 오차 0으로 복사해 캐시 효과를 분리했습니다. 새로 학습하지 않았으므로 파라미터 749,568개와 valid PPL 129.508956은 같습니다. 학습 보고서의 설정·시간은 v0.4.3에서 이어받은 값입니다.

테스트 **7개 통과**: 캐시/전체 logits, 창 경계·입력 수정, 세션 교차 실행, greedy/seed 고정 샘플링, 빈/공백/한글/긴 입력, 잘못된 캐시 거부, 학습 재개·저장 복원.

| CPU 4스레드, 5회 중앙값 | 전체 계산 | 캐시 경로 | 비율 | K/V 텐서 |
|---|---:|---:|---:|---:|
| 창 안, 32회 예측 | 40.13 ms | 22.67 ms | 1.77× | 211.5 KiB |
| 창 넘침, 16회 예측 | 25.04 ms | 20.53 ms | 1.22× | 288.0 KiB |

최대 logits 절대 차이는 **0.00000381**로 허용오차 이내입니다. 동일한 강제 토큰열을 사용하고 첫 문맥 계산도 시간에 포함했습니다. 창 넘침에서는 K/V를 재사용하지 않으며, 마지막 위치만 출력 projection하는 경로 차이·측정 변동이 포함됩니다. 항상 빨라진다는 보장은 없습니다. 메모리 수치는 Python 객체·임시 attention 버퍼를 제외한 K/V 텐서 크기입니다.

## 실행

```bash
# 먼저 v0.4.3 모델을 학습해야 합니다.
python llm/v0.4/v0.4.4/1.train/prepare.py
python llm/v0.4/v0.4.4/2.test/test_invariants.py
python llm/v0.4/v0.4.4/2.test/benchmark.py
python llm/v0.4/v0.4.4/2.test/test.py --split valid
```

API에서 `generate(text, use_cache=False)`로 비교할 수 있고, `seed=1234`로 요청별 샘플링을 재현합니다. 캐시는 추론용 임시 상태라 파일에 저장하지 않습니다. 새 학습은 `1.train/train.py`로도 가능합니다.

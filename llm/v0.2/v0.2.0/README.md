# link_llm — 나만의 작은 언어 모델 (v0.2.0)

**임베딩 도입 (one-hot → `nn.Embedding`).** 토큰을 '독립된 칸'이 아니라 **작은 연속 벡터**로 표현해요.

## 한 걸음 — 입력 표현만 교체

| | v0.1.5 (one-hot) | v0.2.0 (임베딩) |
|---|---|---|
| 토큰 표현 | one-hot (V차원, 독립) | **임베딩 (E차원, 공유·학습)** |
| 입력 크기 | 2V | **2E** |
| 모델 | `Linear(2V,H)→tanh→Linear(H,V)` | `Embedding(V,E)` + `Linear(2E,H)→tanh→Linear(H,V)` |
| 새 파라미터 | — | 임베딩 표 `C` (V×E, 함께 학습) |

앞 2토큰 문맥 · 2층 MLP · 정규화 · 저장 방식은 v0.1.5 **그대로**입니다.

## 핵심 등식 — 임베딩 = one-hot 곱의 압축판

```python
nn.Embedding(V, E)(idx)  ==  F.one_hot(idx, V).float() @ C     # C: V×E
```

- '원-핫 곱하기 가중치' = '표에서 한 줄 꺼내기(lookup)'.
- 결과 형태는 같지만 **E ≪ V 로 압축·공유**되는 게 핵심.

## 구조 (Bengio 2003)

```
(앞앞, 앞) → 임베딩 lookup(각 E) → concat(2E) → fc1 → tanh → fc2 → logits(V)
```

## 왜 임베딩인가

- **one-hot 의 한계** — 토큰마다 독립된 칸이라 "안녕 다음"에서 배운 걸 "반가워 다음"에 못 씁니다.
- **임베딩** — 비슷한 토큰이 비슷한 벡터를 갖게 학습 → 문맥끼리 강점을 공유 → 처음 보는 조합도 일반화.

## 성적 (산문 사전학습)

| 모델 | 검증 PPL | 파라미터 |
|---|---|---|
| v0.1.5 one-hot 2토큰 | **2.90** ← 최저 | 942,281 |
| **v0.2.0 임베딩 2토큰** | 2.94 | 759,753 |
| v0.0.9 카운트 (2토큰+백오프) | 2.96 | 9,512 |

- 카운트(2.96)는 **넘어섭니다** ✅
- one-hot(2.90)에는 **근소하게 뒤져요** — 데이터가 쉽고 작아 '압축·공유'보다 one-hot 의 **구별력**이 아직 큽니다.
- 대신 파라미터가 **19% 적어요**(760K vs 942K) → 지금 임베딩이 주는 건 '정확도'가 아니라 **'효율'**.
- `EMBED`(E)를 키울수록 one-hot 에 가까워지며 좋아지는 경향 — 압축의 이득은 **어휘·데이터가 커야** 납니다.

> 💡 임베딩의 진짜 값어치는 **문맥이 길어질 때** 드러나요.
> one-hot 은 문맥 N토큰에 입력이 `N×V` 로 폭발하지만, 임베딩은 `N×E` 로만 늘어납니다.

## 하이퍼파라미터 실측 메모

`1.train/train.py` 기본값은 검증 PPL 곡선 × 8개 시드로 고른 값이에요.

- **`LR` 이 가장 중요** — Adam 은 `1e-4 ~ 1e-3` 대. `0.05` 면 수렴하지 않고 튕겨 다녀요.
- **`EPOCHS` 는 작게** — 데이터가 쉬워 몇십 에폭이면 바닥에 닿고, 그 뒤엔 과적합.
- **`WEIGHT_DECAY = 0`** — `1e-4` 만 켜도 검증 PPL 이 나빠져요.
- **`LABEL_SMOOTHING = 0`** — `perplexity()` 의 `FLOOR` 가 이미 같은 역할이라 중복.
- **시드 편차가 큼**(±1.2) — 한 번 돌린 숫자로 결론 내지 마세요.

## 실행

> ⚠️ **PyTorch** 필요: `pip install torch`

```bash
python3 1.train/train.py     # 임베딩 MLP 학습 → 0.model/model.pt (+ vocab.json)

```

## 저장 형식 (v0.1.x 와 동일)

| 파일 | 내용 |
|---|---|
| `model.pt` | `state_dict` — 임베딩 표 `emb.weight`(V×E) 포함 |
| `vocab.json` | `{ tokenizer, vocab }` |

- 불러올 때 `emb.weight` 모양에서 **E**, `fc1.weight` 에서 **H** 를 복원합니다.

# v0.4.2 — 학습 안정화·재개

중간에 멈춘 학습을 **같은 배치 다음부터** 이어 갑니다. 예를 들어 84번의 업데이트 중 20번에서 멈추면, 남은 64번을 원래 학습률 일정대로 실행합니다.

- **AdamW**: 가중치 감쇠를 적용합니다.
- **warmup → cosine**: 처음에는 학습률을 올리고 이후 낮춥니다. 마지막은 기본 학습률의 10%입니다.
- **gradient clipping**: gradient norm이 1을 넘으면 줄여 큰 업데이트를 제한합니다.
- **재개 파일**: 현재 가중치·optimizer·scheduler·CPU/장치/Python RNG·배치 순서/위치·최선 가중치·설정·BPE·데이터 해시를 저장합니다.

## 저장과 재개

`training_state.pt`는 에폭 종료 또는 명시한 중단 지점에서 원자적으로 저장합니다. 갑작스러운 종료 시 마지막 저장 지점 이후 계산은 다시 수행합니다. `model.pt`는 전체 학습 완료 후 검증 PPL이 가장 낮은 가중치로 저장합니다. 서로 용도가 다릅니다.

```bash
python llm/v0.4/v0.4.2/2.test/test_invariants.py
python llm/v0.4/v0.4.2/1.train/train.py --device cpu --max-steps 20
python llm/v0.4/v0.4.2/1.train/train.py --device cpu \
  --resume llm/v0.4/v0.4.2/0.model/training_state.pt
python llm/v0.4/v0.4.2/2.test/test.py --split valid
```

재개할 때 원래 설정과 총 에폭 수를 유지해야 합니다. 데이터·설정·토크나이저·장치·PyTorch·스레드 수가 다르면 거부합니다. 정확한 재현은 동일 CPU 환경에서 검증했습니다. CUDA/MPS RNG 저장 경로는 제공하지만 해당 장치의 수치 재현성은 미검증입니다. 체크포인트 가중치는 Git에서 제외합니다.

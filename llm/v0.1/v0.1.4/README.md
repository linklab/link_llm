# link_llm — 나만의 작은 언어 모델 (v0.1.4)

**2토큰 문맥 신경망.** 지금까지 신경망은 앞 1토큰만 봤는데, 상대인 v0.0.9(카운트)는 앞 2토큰을 봤어요.
문맥을 맞춰 **공정한 대결**로 만듭니다.

## 한 걸음 — 문맥 1토큰 → 2토큰

| | v0.1.0 ~ v0.1.3 | v0.1.4 |
|---|---|---|
| 문맥 | 앞 1토큰 | **앞 2토큰 `(prev2, prev1)`** |
| 입력 | one-hot (V) | one-hot 2개 이어붙임 (2V) |
| 모델 | `Linear(V, H)`→tanh→`Linear(H, V)` | `Linear(2V, H)`→tanh→`Linear(H, V)` |
| 저장 | `model.pt` (state_dict) | 동일 — 입력 폭만 2V |
| v0.0.9 와 비교 | 문맥이 짧아 불리 | **같은 2토큰 = 공정** |

구조·학습·정규화는 그대로, **입력만 넓혔어요.**

## 문장 맨 앞의 빈자리 — `<PAD>`

- 두 번째 토큰을 맞힐 땐 '앞앞 토큰'이 없어요 → **`<PAD>`**(어휘 0번)로 채웁니다.
- 학습·추론이 똑같이 "앞앞이 없으면 PAD" 규칙을 써서 일관돼요.

## 성적 (산문 사전학습) — 카운트를 넘어섭니다 ✅

| 버전 | 검증 PPL | top-1 | 파라미터 |
|---|---|---|---|
| v0.0.9 (카운트, 2토큰) | 2.96 | 73.5% | 9,512 |
| **v0.1.4 (신경망, 2토큰)** | **2.90** | 73.6% | 942,281 |
| v0.1.3 (신경망, 1토큰) | 4.04 | 64.9% | 628,168 |

- **문맥을 맞추자 순위가 바뀝니다** — 1토큰 4.04 → 2토큰 2.90.
- 다만 격차는 **0.06** 뿐이고 파라미터는 **99배**. 이겼지만 압도하진 못했어요.
- 저장되는 건 **검증 PPL 최저 에폭**(epoch 22)의 가중치입니다.
- 쉬운 산문이라 격차가 작아요 — 진짜 격차는 대화 SFT 인 **v0.5** 에서.

## 왜 이길 수 있나

1. **같은 문맥(2토큰)** — 더 이상 문맥 길이로 손해 보지 않아요.
2. **부드러운 확률(softmax)** — 카운트는 처음 보는 조합에 `FLOOR=1e-4` 라는 큰 벌점을 주지만,
   신경망은 어휘 전체에 확률을 나눠 그 '절벽'을 피합니다.

> ⚠️ `LABEL_SMOOTHING` 은 기본 **0** 이에요 — `perplexity()` 의 `FLOOR` 가 이미 같은 역할을 해서,
> 켜면 오히려 검증 PPL 이 나빠집니다.

## 실행

> ⚠️ **PyTorch** 필요: `pip install torch`

```bash
python3 1.train/train.py     # 2토큰 문맥 학습 → 0.model/model.pt (+ vocab.json)
python3 2.test/test.py       # 학습/검증 PPL + 이어쓰기 예시
```

- 검증 PPL 이 **2.96 아래**면 "같은 문맥에서 신경망 승".
- 여러 버전 대결표는 다음 버전 **v0.1.5 캡스톤**에서 한 번에 출력합니다.

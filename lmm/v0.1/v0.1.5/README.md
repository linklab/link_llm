# link_lmm — 나만의 작은 언어 모델 (v0.1.5)

**기준선 대결 (캡스톤).** 신경망 시대(v0.1.x)를 마무리하며,
**카운트 vs 신경망**을 같은 자(퍼플렉서티)로 나란히 재서 "신경망이 정말 이겼나?"를 확인해요.

## v0.1.4 → v0.1.5, 무엇이 바뀌었나요?

> **모델이 아니라 '비교'가 새 개념.** 모델·학습은 v0.1.4(2토큰 문맥) 그대로이고,
> 여러 버전을 **같은 학습/검증 데이터로 PPL** 재서 대결표를 뽑는 도구를 더했어요.

## 대결 방법

```bash
# (torch 환경) 비교할 신경망 버전들을 먼저 학습해 model.json 을 만들어 두고…
python3 lmm/v0.1/v0.1.0/3.train/train.py
python3 lmm/v0.1/v0.1.3/3.train/train.py
python3 lmm/v0.1/v0.1.4/3.train/train.py    # 2토큰 문맥
python3 lmm/v0.1/v0.1.5/3.train/train.py
# 대결표 출력
python3 lmm/v0.1/v0.1.5/4.test/test.py
```

실제 출력 (각 버전 `3.train/train.py` 의 기본 하이퍼파라미터로 학습했을 때):
```
버전     종류   학습PPL  검증PPL   격차   top-1   후보有
v0.0.9   카운트   2.79   34.39   12.3배   45.5%   72.0%   ← 개수 세기 기준선(앞 2토큰)
v0.1.0   신경망  19.74   66.45    3.4배   33.9%   83.6%   ← full-batch 수동 SGD (덜 수렴)
v0.1.1   신경망   5.12   40.63    7.9배   40.2%   83.6%   ← 미니배치로 훨씬 더 학습
v0.1.2   신경망   5.21   39.71    7.6배   40.7%   83.6%   ← Adam
v0.1.3   신경망   5.29   39.37    7.4배   40.7%   83.6%   ← 정규화·초기화 (여기까지 1토큰)
v0.1.4   신경망   3.82   31.98    8.4배   46.6%   83.6%   ← 앞 2토큰(카운트와 같은 조건)
v0.1.5   신경망   3.82   31.98    8.4배   46.6%   83.6%
→ 검증 PPL 최저: v0.1.4 (신경망) = 31.98
  → 신경망이 카운트 기준선(v0.0.9 34.39)을 이겼어요. ✅
→ top-1 정확도 최고: v0.1.4 (신경망) = 46.6%
→ '정답이 후보에 있음': 카운트 72.0%  vs  신경망 83.6%
```

읽는 법 세 가지:

1. **문맥 1토큰(v0.1.0~3)은 카운트(앞 2토큰)를 못 이겨요.** 같은 2토큰으로 맞춘
   v0.1.4 에서야 34.39 → **31.98** 로 넘어섭니다 — "이긴 건 신경망이라서가 아니라
   **같은 문맥에서** 부드럽게 확률을 나눠서"가 이 대결의 결론이에요.
2. **`후보有`(coverage) 72.0% vs 83.6%** 가 카운트의 근본 한계예요. 카운트는 검증 토큰의
   28% 에서 정답을 표에 아예 갖고 있지 않습니다. PPL 에서는 `FLOOR` 가 메워줘 잘 안 보이는
   차이가, 이 열에서는 그대로 드러나요.
3. **지표마다 승자가 다를 수 있어요.** 여기서는 v0.1.4 가 둘 다 1등이지만, v0.2.0(임베딩)까지
   넣으면 PPL 은 v0.1.5 가, top-1 정확도는 v0.2.0 이 이깁니다 (33.39 vs 31.98 / 47.6% vs 46.6%).

- **검증 PPL 이 낮을수록** '처음 보는 것'에 강한 모델이에요.
- **1토큰(v0.1.0~3) vs 2토큰(v0.1.4~5)** 을 나란히 보면 '문맥 길이'의 효과가 한눈에 보여요.
- 아직 학습 안 된 버전이나 torch 없는 신경망 버전은 자동으로 **건너뛰고** 이유를 알려줘요.

## 공정한 비교

모든 버전이 같은 토크나이저·`<END>`·`perplexity()` 공식을 쓰고, **확률 엔진(개수 표 ↔ 신경망)만** 달라요.
특히 v0.1.4~5 는 카운트와 **문맥 길이(2토큰)까지 같아** 완전한 사과 대 사과 비교예요.

## 완결성 — 웹앱에서도

`model.json` 을 `type` 으로 구분해 로드하므로, 웹앱(`web_service`)에서 v0.1.5 를 골라 **대화로도** 평가할 수 있어요.
(대결표는 `4.test/test.py`, 대화는 웹앱 — 둘 다 됩니다.)

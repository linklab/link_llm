# models 폴더 (v0.0.4)

학습이 끝난 **모델 파일(`model.json`)** 이 저장되는 곳이에요.
(`train/train.py` 를 실행하면 자동으로 만들어집니다.)

## 이 버전 모델의 특징

- **문맥 길이:** 앞 1단어 **와** 2단어 (`max_order = 2`, 표가 **`"1"`, `"2"` 두 개!**)
- **토크나이저:** `whitespace`
- **문장 끝(`<END>`):** 학습함
- **v0.0.3 과 차이:** 백오프(backoff)를 위해 **표를 두 개** 저장해요.
  - 표2: 앞 2단어 → 다음 (자세함)
  - 표1: 앞 1단어 → 다음 (덜 자세하지만 웬만하면 있음)

## model.json 예시

```json
{
  "max_order": 2,
  "tokenizer": "whitespace",
  "tables": {
    "2": { "나는 아침에": { "밥을": 1, "우유를": 1, "학교에": 1 } },
    "1": { "나는": { "아침에": 5, "저녁에": 4, "주말에": 4, "코딩을": 1 } }
  }
}
```

문장을 만들 때 **표2에서 찾고, 없으면 표1로 줄여** 다시 찾아요(백오프).
덕분에 `"나는"` 한 단어만 입력해도 표1 덕분에 시작할 수 있어요.

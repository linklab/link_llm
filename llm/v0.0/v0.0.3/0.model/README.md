# models 폴더 (v0.0.3)

학습이 끝난 **모델 파일(`model.json`)** 이 저장되는 곳이에요.
(`1.train/train.py` 를 실행하면 자동으로 만들어집니다.)

## 이 버전 모델의 특징

- **문맥 길이:** 앞 **2단어** (`max_order = 2`)
- **토크나이저:** `whitespace`
- **문장 끝(`<END>`):** **학습함!** ← v0.0.2 와의 핵심 차이
- **v0.0.2 와 차이:** 문장 끝에 `<END>` 라는 가짜 토큰을 함께 세어 둬요.
  그래서 "이 말 다음엔 문장이 끝난다" 를 모델이 알게 됩니다.

## model.json 예시

```json
{
  "max_order": 2,
  "tokenizer": "whitespace",
  "tables": {
    "2": {
      "나는 아침에": { "밥을": 1, "우유를": 1, "학교에": 1 },
      "밥을 먹습니다": { "<END>": 1 },
      "학교에 갑니다": { "<END>": 1 }
    }
  }
}
```

`"밥을 먹습니다"` 다음에 `"<END>"` 가 있으니, 문장을 만들다 여기에 이르면 자연스럽게 멈춰요.

# link_lmm — 나만의 작은 언어 모델 (v0.0.1)

중학생도 이해할 수 있는 **아주 기본적인** 언어 모델(LMM)이에요.
어려운 수학이나 신경망(딥러닝) 없이, **"단어를 세는 것"** 만으로 문장을 만들어 봅니다.

## 언어 모델이 뭐예요?

언어 모델은 **"이 단어 다음에는 어떤 단어가 나올까?"** 를 맞히는 프로그램이에요.
휴대폰 자판에서 다음 단어를 추천해 주는 기능과 비슷해요.

우리 모델의 원리는 딱 두 줄로 정리돼요:

1. **학습**: 문장들을 보고 "어떤 단어 뒤에 어떤 단어가 몇 번 나왔는지" 표를 만든다.
2. **생성**: 그 표를 보고 가장 자주 나온 단어를 계속 이어 붙여 문장을 만든다.

## 폴더 구조

```
v0.0.1/
├── base.py         # NGramLM 기반 클래스 (읽기·학습·저장·생성 전부 — 뒤 버전들이 물려받음)
├── model.py        # 이 버전 설정 (ORDERS=[1])
├── train/          # 학습(공부)시키는 곳
│   ├── data.txt    #   - 배울 문장들 (여기에 문장을 더 추가할 수 있어요)
│   └── train.py    #   - 얇은 실행기 (실제 학습 코드는 base.py)
├── models/         # 학습이 끝난 모델이 저장되는 곳
│   └── model.json  #   - train.py 를 실행하면 자동으로 생겨요
└── test/           # 만든 모델을 시험해 보는 곳
    └── test.py     #   - 얇은 실행기 (실제 생성 코드는 base.py)
```

> v0.0.1 은 언어 모델의 **기반 클래스** `NGramLM` 을 [`base.py`](base.py) 에 통째로 담아요.
> 뒤 버전들(v0.0.2 ...)은 이 클래스를 물려받아 **바뀌는 함수만** 자기 `base.py` 에 덧붙입니다.

## 사용 방법

준비물: **Python 3** (추가 설치 필요 없음! 기본 기능만 사용해요.)

### 1단계 — 학습시키기

```bash
python3 train/train.py
```

실행하면 `models/model.json` 파일이 만들어져요.

### 2단계 — 문장 만들어 보기

```bash
python3 test/test.py
```

배운 문장을 바탕으로 새 문장을 만들어 보여줍니다.

## 더 해보기 (직접 바꿔보세요!)

- `train/data.txt` 에 **내가 좋아하는 문장**을 더 추가한 뒤 다시 학습시켜 보세요.
- `test/test.py` 의 시작 단어 목록을 바꿔 보세요.
- 학습을 다시 하면(`train.py` 실행) 모델이 새로운 문장을 배웁니다.

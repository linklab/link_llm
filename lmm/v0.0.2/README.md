# link_lmm — 나만의 작은 언어 모델 (v0.0.2)

중학생도 이해할 수 있는 **아주 기본적인** 언어 모델(LMM)이에요.
어려운 수학이나 신경망(딥러닝) 없이, **"단어를 세는 것"** 만으로 문장을 만들어 봅니다.

## v0.0.1 → v0.0.2, 무엇이 바뀌었나요?

> **문맥을 "앞 단어 1개"에서 "앞 단어 2개"로 넓혔어요.**

- v0.0.1: `"우리는"` 다음 단어만 보고 골랐어요.
- v0.0.2: `"우리는 함께"` 처럼 **앞 두 단어**를 보고 다음 단어를 골라요.

앞 단어를 하나 더 보기 때문에 배운 문장을 더 잘 따라가서, 문장이 훨씬 자연스러워집니다.
원리는 그대로예요 — 여전히 "어떤 말 뒤에 어떤 단어가 몇 번 나왔는지" 를 셀 뿐,
그 '어떤 말'이 한 단어에서 → 두 단어 짝으로 넓어졌을 뿐입니다.

또한 학습 문장(`train/data.txt`)을 **더 다양하고 많게** 늘렸어요.

## 언어 모델이 뭐예요?

언어 모델은 **"이 다음에는 어떤 단어가 나올까?"** 를 맞히는 프로그램이에요.
휴대폰 자판에서 다음 단어를 추천해 주는 기능과 비슷해요.

1. **학습**: 문장들을 보고 "앞 두 단어 뒤에 어떤 단어가 몇 번 나왔는지" 표를 만든다.
2. **생성**: 그 표를 보고 다음 단어를 계속 이어 붙여 문장을 만든다.

## 저장되는 모델 형식 (모든 버전 공통)

모든 버전이 `{ max_order, tokenizer, tables }` 형식으로 통일돼요.
v0.0.2 는 앞 2단어만 보므로 `tables` 에 `"2"` 표 하나만 들어갑니다.

```json
{
  "max_order": 2,
  "tokenizer": "whitespace",
  "tables": {
    "2": {
      "우리는 함께": { "공부합니다": 1, "놀았습니다": 1, "밥을": 1 },
      "오늘 날씨가": { "정말": 1, "조금": 1 }
    }
  }
}
```

## 폴더 구조

```
v0.0.2/
├── base.py         # v0.0.1 을 상속만 함 (새 코드 없음! 설정 ORDERS=[2] 만으로 앞 2단어)
├── model.py        # 이 버전 설정 (ORDERS=[2])
├── train/
│   ├── data.txt    # 배울 문장들
│   └── train.py    # 얇은 실행기 (실제 학습 코드는 base.py 사슬)
├── models/
│   └── model.json  # train.py 를 실행하면 자동으로 생겨요
└── test/
    └── test.py     # 얇은 실행기 (실제 생성 코드는 base.py 사슬)
```

## 사용 방법

준비물: **Python 3** (추가 설치 필요 없음!)

### 1단계 — 학습시키기

```bash
python3 train/train.py
```

### 2단계 — 문장 만들어 보기

```bash
python3 test/test.py
```

## 더 해보기

- `train/data.txt` 에 문장을 더 추가한 뒤 다시 학습시켜 보세요.
- `test/test.py` 의 시작 두 단어를 바꿔 보세요.
- `model.py` 의 `ORDERS` 를 `[3]` 으로 바꾸면 "앞 세 단어"를 보는 모델도 만들 수 있어요.

## 한계 (→ 다음 버전 예고)

문맥이 넓어지면 "그 두 단어 짝을 한 번도 못 본" 경우가 생겨 문장이 일찍 끊길 수 있어요.
이 문제는 다음 버전에서 **백오프**(문맥을 짧게 줄여 다시 시도)로 다룰 예정이에요.

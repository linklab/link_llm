# 0.model 폴더 (v0.0.8)

- `lm.py` : 이 버전의 코드 (NGramLM + Model). v0.0.7 을 상속해 **대화 기능**을 더했어요.
- `model.json` : 학습 결과 (`1.train/train.py` 실행 시 자동 생성).

## 이 버전 모델의 특징

- **문맥 길이:** 앞 1 + 2단어 (`max_order = 2`, 표 `"1"`, `"2"`)
- **토크나이저:** `punct` (문장부호 분리) — **역할 토큰 `<사용자>`·`<봇>`** 도 하나의 토큰으로 다뤄요.
- **문장 끝(`<END>`):** 학습함
- **v0.0.7 과 차이:** 대화용 **역할 토큰·`chat()` 기계**를 더했어요. 다만 지금 사전학습 데이터는
  **산문**(공용 데이터 `data/pretrain`)이라 실제 표엔 `<사용자>`·`<봇>` 이 안 나와요 —
  이 토큰들이 실제로 표에 등장하는 건 **v0.5(SFT)** 에서 대화 데이터로 학습할 때부터예요.
  (아래 예시는 그 대화 형식 기계가 어떻게 동작하는지 보여주는 그림이에요.)

## model.json 예시

```json
{
  "max_order": 2,
  "tokenizer": "punct",
  "tables": {
    "2": {
      "안녕 <봇>": { "안녕하세요": 1 },
      "고마워 <봇>": { "천만에요": 1 },
      "안녕하세요 !": { "<END>": 2 }
    },
    "1": {
      "<봇>": { "안녕하세요": 2, "천만에요": 2, "저는": 5, "..." : 1 }
    }
  }
}
```

`"{내 말의 마지막 토큰} <봇>"` 뒤에 봇의 답 첫 단어가 오도록 배워요.
그래서 `<사용자> 안녕 <봇>` 까지 주면 그 뒤로 `안녕하세요 !` 가 이어집니다.

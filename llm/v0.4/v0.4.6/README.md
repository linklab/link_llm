# v0.4.6 — 재현 가능한 GPT base 캡스톤

**검증으로 선택한 모델을 고정하고, 새 독립 문서로 평가한 뒤 처음부터 재학습해 같은 가중치가 나오는지 확인합니다.**

시험지를 보기 전에 수험생과 시험 방식을 정하는 것과 같습니다. 최종 평가 점수를 본 뒤 모델을 다시 고르거나 학습 조건을 바꾸지 않습니다.

## 이번에 고정한 것

| 항목 | 설정 |
|---|---|
| 모델 | v0.4.5의 valid 최저 RoPE 후보·248,960파라미터 |
| 구조 | decoder-only·4층·폭64·4헤드·문맥64·가중치 공유 |
| 나머지 부품 | LayerNorm·GELU FFN256·일반 멀티헤드; 현대 구조를 한꺼번에 합치지 않음 |
| 토크나이저 | train-only byte BPE·768토큰·원문 가역성 |
| 학습 | train320문서·4에폭·194,720정답 토큰·시드1234 |
| 최적화 | AdamW 0.003·warmup10·cosine·clip1·배치128 |
| 고정 기록 | 가중치·구조·BPE·데이터·코드 해시와 학습량 |
| 사용 범위 | 산문 이어쓰기 base 모델; 대화 SFT는 v0.5 범위 |

v0.4.5에서 선택한 가중치를 바꾸지 않고 v0.4.6으로 내보냈습니다. `freeze.json`을 먼저 만든 뒤 새 문서를 작성하고, 모델 고정 기록과 데이터 파일의 해시를 `manifest.json`으로 연결했습니다. 최종 평가기는 변경된 모델·코드·토크나이저·데이터를 거부합니다. 가중치는 텐서 값의 의미적 해시로 검증하며 저장 파일의 바이트 해시는 출처 기록입니다.

## 최종 결과

| 평가 집합 | 문서 | PPL ↓ | 원문 NLL/byte ↓ | top-1 |
|---|---:|---:|---:|---:|
| 모델 선택에 쓴 valid | 80 | 150.858368 | 2.100910 | 25.14% |
| **새 독립 최종 평가** | 12 | **181.100066** | **2.161931** | **23.84%** |
| 기존 v0.4.1 test (참고) | 80 | 166.859699 | 2.151931 | 24.43% |

새 문서는 도자기·지하철·종이접기·재활용·인쇄·그림자극의 6개 주제, 각2개입니다. 기존 모든 분할과 정규화 중복 및 선언된 주제·템플릿의 겹침을 검사했습니다. AI 도움으로 직접 작성한 **12개의 합성 문서**이므로 광범위한 언어 능력을 대표하지 않습니다. 기존 test는 과거에 이미 보고했으므로 새 독립 평가와 구분합니다.

같은 어휘의 균등 확률 기준선은 새 평가에서 PPL763, NLL/byte 2.757183입니다. 이보다 낮은 NLL이 유창한 문장 생성이나 지시 이행을 뜻하지는 않습니다.

**생성 품질은 아직 낮습니다.** 고정 프롬프트6개 모두 이어쓰기 부분이 공백/빈 내용이었습니다. 예를 들어 `오늘은` 뒤에 공백을 반복했습니다. 캐시를 켜고 끈 생성 결과는 일치했지만, 실용적인 대화 모델은 아닙니다.

## 재현·검증

- 처음부터 같은 CPU 설정으로 재학습한 **모든 가중치·구조·BPE 해시가 정확히 일치**했습니다. 재현 학습·에폭별 검증은 44.77초였습니다.
- 의미적 가중치 SHA-256: `07ae988ade6a2e049356d153f27f38db18cedd3b03cd47c95e175e84e150fea7`.
- 전체 자동 테스트 **73개 통과**: v0.3.4 16개, v0.4.0~v0.4.6 각각12·16·3·6·7·9·4개.
- 웹서버의 실제 버전 검색·로더·일반/공백/빈 입력 생성 경로에서 v0.4.2~v0.4.6을 확인했습니다. 브라우저 화면·원격 접속까지 검사한 것은 아닙니다.
- 정확한 재학습 검증 환경: Python 3.12.14, PyTorch 2.13.0, CPU4스레드. CUDA/MPS 재현성은 검증하지 않았습니다.

```bash
# 저장소 루트, PyTorch가 있는 환경 (이번 실행: conda activate link_llm)
python llm/v0.4/v0.4.6/2.test/test_invariants.py
# Git에 없는 가중치를 처음부터 재현·저장 (고정 설정만 사용)
python llm/v0.4/v0.4.6/1.train/train.py \
  --output-dir llm/v0.4/v0.4.6/0.model
# 고정 모델과 독립 평가 자료의 무결성 검사·최종 평가
python data/pretrain/v0.4.6/seal.py
python llm/v0.4/v0.4.6/2.test/test.py
python web_service/server.py
```

`train.py`에서 출력 경로를 생략하면 임시 폴더에서 재현해 기존 모델을 보존합니다. 이미 있는 `freeze.json`과 평가 봉인은 덮어쓰지 않습니다. 최초 동결용 `freeze.py`는 v0.4.5 선택 모델을 사용하며, 새 평가 문서 작성 전에만 새 동결을 허용합니다. 가중치 파일은 Git 제외이고 설정·코드·평가 자료·보고서는 추적합니다.

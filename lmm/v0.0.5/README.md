# link_lmm — 나만의 작은 언어 모델 (v0.0.5)

누구나 쉽게 이해할 수 있는 **아주 기본적인** 언어 모델(LMM)이에요.
어려운 신경망(딥러닝) 없이, **"단어를 세는 것"** 으로 문장을 만들어 봅니다.

## v0.0.4 → v0.0.5, 무엇이 바뀌었나요?

> **'개수' 를 '확률' 로 바꾸고, '온도(temperature)' 로 다양성을 조절해요.**
> (백오프는 v0.0.4 그대로 유지해요.)

- v0.0.4 는 항상 **가장 많이 나온 단어**만 골랐어요 → 늘 똑같은 답.
- v0.0.5 는 개수를 **확률**로 바꿔서, 그 확률대로 **'뽑기'** 를 합니다 → 매번 조금씩 다른 답.

예) `"우리는 함께"` 다음에 `공부합니다(2)`, `놀았습니다(1)`, `밥을(1)` 이 나왔다면
→ 공부합니다 **50%**, 놀았습니다 **25%**, 밥을 **25%** 확률로 뽑아요.

### 온도(temperature)란?

다양성을 조절하는 다이얼이에요. (무게 = 개수 ^ (1 / 온도))
웹앱 슬라이더는 **0.0 ~ 1.0** 범위, 기본값 **0.7** 이에요.

| 온도 | 이름표 | 결과 |
|------|--------|------|
| 0.0 ~ 0.3 | 안정적 | 많이 나온 단어가 더 세짐 → 뻔한 문장 |
| 0.4 ~ 0.7 | 균형 | 개수 비율에 가깝게 뽑음 |
| 0.8 ~ 1.0 | 다양함 | 확률이 평평해짐 → 다양한 문장 |

이 **'확률 + 온도로 뽑기'** 가 바로 진짜 **GPT 가 문장을 만드는 방식**이에요!

### 백오프도 그대로

문맥을 찾을 때 **앞 2단어 → 없으면 앞 1단어**로 줄여 다시 찾는 백오프(v0.0.4)는
그대로 유지돼요. 그래서 1단어 입력도, 처음 보는 2단어 짝도 잘 이어집니다.

## 사용 방법

```bash
python3 3.train/train.py     # 1) 학습 (백오프용 표1, 표2 를 함께 만듦 — v0.0.4 와 동일)
python3 4.test/test.py       # 2) 온도 0.2 / 0.5 / 1.0 로 문장을 만들어 비교
```

웹앱(`web_service`)에서는 화면 아래 **다양성(온도) 슬라이더**로 직접 조절할 수 있어요.

## 버전

- **v0.0.2** — 앞 단어 2개로 예측

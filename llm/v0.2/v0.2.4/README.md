|---|---|---|---|

## ① 최근접이웃 — 가장 직접적인 증거

```
[강아지] → 개구리(0.72) · 부엉이(0.70) · 코알라(0.69) · 코끼리(0.68) · 거북이(0.67)
[바다]   → 놀이터(0.90) · 카페(0.89) · 공원(0.77) · 과학관(0.76) · 빵집(0.76)
[사과]   → 간식(0.83) · 출출해서(0.44) · 음악(0.41) · 카레(0.41) · 햇살(0.41)
[먹었다] → 맛있었다(0.32) · 좋아졌다(0.32) · 달았다(0.28) · 두드렸다(0.25) · 흔들린다(0.24)
```

- **이웃이 전부 같은 부류**예요 — `강아지`는 동물만, `바다`는 장소만, `사과`는 먹을 거리만.
  one-hot 이었다면 불가능한 일 — 토큰마다 독립된 칸이라 '비슷함' 자체를 표현할 방법이 없거든요.
- 숫자로 보면 더 분명해요. 같은 부류끼리 평균 코사인 유사도:

  | 부류 | 평균 유사도 |
  |---|---|
  | 장소 (19개) | **+0.92** |
  | 동물 (26개) | **+0.65** |
  | 음식 (29개) | **+0.60** |
  | 무작위 쌍 | +0.01 |

- **조사는 따로 모여요** — `##를`·`##에` 같은 조사 토큰끼리는 평균 **+0.02** 로 어간과 섞이지 않아요.
  v0.0.6 이 조사를 별도 토큰으로 떼어낸 덕분에 **어간 임베딩이 순수하게 의미만** 담게 됐습니다.
- `먹었다` 는 먹기·맛 관련 **과거형 동사**와 묶였고, 유사도(0.3대)는 명사보다 낮아요 —
  동사는 문맥이 더 다양하기 때문입니다.

## ② PCA vs ③ t-SNE

| | 방식 | 결과 | 강점 |
|---|---|---|---|
| **PCA** | 선형 — 분산이 가장 큰 두 방향 | 설명된 분산 **11.6%** | 전체 퍼짐 · 빠름 · 해석 가능 |
| **t-SNE** | 비선형 — 이웃 관계 보존 | 최종 KL **2.00** | **덩어리(군집)** 가 잘 보임 |

- **PCA 의 11.6% 는 낮은 게 정상이에요.** 128차원을 2차원에 눌렀으니 대부분의 정보가 버려집니다.
  그래도 "얼마나 버렸나"를 **숫자로 알려준다**는 게 PCA 의 장점이에요.
- **t-SNE 는 그 숫자가 없어요.** 대신 이웃 관계를 살려 덩어리를 보여줍니다.
- ⚠️ **t-SNE 의 덩어리 사이 '거리'는 의미가 없어요.** 이웃 관계만 믿으세요.

> 💡 t-SNE 학습 로그에서 KL 이 13.5 → 15.3 으로 **올랐다가** 2.0 으로 급락하는데 정상이에요.
> 초반 250스텝은 **early exaggeration**(P 를 4배 부풀려 덩어리를 먼저 뭉치게 함) 구간이라
> KL 값의 스케일 자체가 다릅니다.

## autograd 를 다시 쓰는 곳

t-SNE 는 저차원 좌표 `Y` 를 **파라미터로 두고** KL(P‖Q) 를 줄이는 최적화예요.
미분 공식을 직접 유도하지 않고 `loss.backward()` 한 줄로 끝냅니다.

```python
Y = (torch.randn(n, 2) * 1e-2).requires_grad_(True)   # 좌표가 곧 학습 대상
opt = torch.optim.Adam([Y], lr=100.0)
...
loss = (P * (P.log() - Q.log())).sum()                 # KL(P‖Q)
loss.backward(); opt.step()
```

v0.1.0 에서 배운 autograd 를 **신경망이 아닌 것**에 쓰는 예예요 —
"autograd 는 신경망 전용이 아니다" 를 보여줍니다.

# models 폴더 (v0.0.5)

학습이 끝난 **모델 파일(`model.json`)** 이 저장되는 곳이에요.
(`1.train/train.py` 를 실행하면 자동으로 만들어집니다.)

## 이 버전 모델의 특징

- **문맥 길이:** 앞 1단어 + 2단어 (`max_order = 2`, 표 `"1"`, `"2"`)
- **토크나이저:** `whitespace`
- **문장 끝(`<END>`):** 학습함
- **저장된 모델은 v0.0.4 와 똑같아요!** 🤔

## 왜 v0.0.4 와 같은가요?

v0.0.5 가 새로 도입한 **확률 + 온도(temperature)** 는 **문장을 만들 때(생성)** 쓰는 방법이에요.
'개수를 어떻게 세느냐'(=저장되는 모델)는 바뀌지 않았어요. 그래서 `model.json` 은 v0.0.4 와 동일합니다.

- v0.0.4: 표에서 **가장 많이 나온** 것만 고름 (그리디)
- v0.0.5: 표의 개수를 **확률로 바꿔 뽑고**, 온도로 다양성 조절

즉 **같은 표(model.json)를 어떻게 활용하느냐**가 달라진 버전이에요.

## model.json 예시

```json
{
  "max_order": 2,
  "tokenizer": "whitespace",
  "tables": {
    "2": { "우리는 함께": { "공부합니다": 1, "놀았습니다": 1, "밥을": 1 } },
    "1": { "나는": { "아침에": 5, "저녁에": 4, "주말에": 4 } }
  }
}
```

`"우리는 함께"` 뒤 후보들의 **개수 비율**이 그대로 뽑기 확률이 돼요. (온도로 그 확률을 조절)

## 한 걸음 — 분석 도구 3개

| # | 도구 | 무엇을 보나 | 어떻게 |
|---|---|---|---|
| ① | **최근접이웃** | 이 토큰과 가까운 토큰들 | 코사인 유사도 |
| ② | **PCA** | 전체가 어떻게 퍼져 있나 | `torch.linalg.svd` (선형) |
| ③ | **t-SNE** | 어떤 **덩어리**가 있나 | KL(P‖Q) 를 autograd 로 최소화 (비선형) |

## ① 최근접이웃 — 가장 직접적인 증거

```
[강아지]  → 나비(0.93) · 원숭이(0.93) · 여우(0.92) · 꿀벌(0.92) · 사자(0.92)
[먹었다]  → 좋아졌다(0.30) · 달았다(0.29) · 음미했다(0.29) · 맛있었다(0.26) · 따뜻했다(0.20)
[따뜻한]  → 점심으로(0.73) · 간식으로(0.70) · 출출해서(0.69) · 빵은(0.50) · 귤은(0.49)
```

- **`강아지` 의 이웃 5개가 전부 동물**이에요 (0.92~0.93). one-hot 이었다면 불가능한 일 —
  토큰마다 독립된 칸이라 '비슷함' 자체를 표현할 방법이 없거든요.
- `먹었다` 는 먹기·맛 관련 **과거형 동사**, `따뜻한` 은 **음식 문맥** 단어와 묶였어요.
- **유사도 크기가 부류마다 달라요.** 동물은 0.92 대로 바짝 붙어 있는데 동사는 0.30 언저리예요 —
  동물 이름은 문장에서 거의 같은 자리에 오지만, 동사는 문맥이 더 다양하기 때문입니다.

## ② PCA vs ③ t-SNE

| | 방식 | 결과 | 강점 |
|---|---|---|---|
| **PCA** | 선형 — 분산이 가장 큰 두 방향 | 설명된 분산 **10.1%** | 전체 퍼짐 · 빠름 · 해석 가능 |
| **t-SNE** | 비선형 — 이웃 관계 보존 | 최종 KL **2.12** | **덩어리(군집)** 가 잘 보임 |

- **PCA 의 10.1% 는 낮은 게 정상이에요.** 128차원을 2차원에 눌렀으니 대부분의 정보가 버려집니다.
  그래도 "얼마나 버렸나"를 **숫자로 알려준다**는 게 PCA 의 장점이에요.
- **t-SNE 는 그 숫자가 없어요.** 대신 이웃 관계를 살려 덩어리를 보여줍니다.
- ⚠️ **t-SNE 의 덩어리 사이 '거리'는 의미가 없어요.** 이웃 관계만 믿으세요.

> 💡 t-SNE 학습 로그에서 KL 이 13.5 → 15.8 로 **올랐다가** 2.2 로 급락하는데 정상이에요.
> 초반 250스텝은 **early exaggeration**(P 를 4배 부풀려 덩어리를 먼저 뭉치게 함) 구간이라
> KL 값의 스케일 자체가 다릅니다.

## autograd 를 다시 쓰는 곳

t-SNE 는 저차원 좌표 `Y` 를 **파라미터로 두고** KL(P‖Q) 를 줄이는 최적화예요.
미분 공식을 직접 유도하지 않고 `loss.backward()` 한 줄로 끝냅니다.

```python
Y = (torch.randn(n, 2) * 1e-2).requires_grad_(True)   # 좌표가 곧 학습 대상
opt = torch.optim.Adam([Y], lr=100.0)
...
loss = (P * (P.log() - Q.log())).sum()                 # KL(P‖Q)
loss.backward(); opt.step()
```

v0.1.0 에서 배운 autograd 를 **신경망이 아닌 것**에 쓰는 예예요 —
"autograd 는 신경망 전용이 아니다" 를 보여줍니다.

  `perplexity` 를 낮추면 지역 구조가, 높이면 전역 구조가 강조됩니다.

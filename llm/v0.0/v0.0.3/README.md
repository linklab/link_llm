# link_llm — 나만의 작은 언어 모델 (v0.0.3)

신경망 없이 **"단어를 세는 것"** 만으로 문장을 만드는 언어 모델이에요. (Python 3 만 있으면 실행)

## v0.0.2 → v0.0.3, 무엇이 바뀌었나요?

> **문장이 '끝나는 것'도 배웁니다.**

- v0.0.2 까지는 문장이 언제 끝나는지 몰라서, 정해진 길이가 될 때까지 억지로
  단어를 이어붙였어요. 그래서 어색하게 늘어지거나 툭 끊기기도 했죠.
- v0.0.3 은 각 문장 끝에 **'문장 끝 표시'(`<END>`)** 를 붙여서 학습해요.
  그러면 "이런 말 다음에는 문장이 끝나더라" 를 배우고, 문장을 만들 때
  `<END>` 가 나오면 **자연스럽게 멈춥니다.**

예) `"함께 공부합니다"` 다음 → `<END>` (여기서 문장이 끝난다!)

원리는 그대로예요 — 문장 끝에 `<END>` 라는 '가짜 단어' 를 하나 추가해서,
끝나는 것도 함께 셀 뿐입니다. 문맥은 v0.0.2 와 같은 **앞 두 단어**를 봅니다.

## 저장되는 모델 형식 (모든 버전 공통)

`<END>` 가 다음 단어 후보로 등장할 수 있어요.

```json
{
  "max_order": 2,
  "tokenizer": "whitespace",
  "tables": {
    "2": {
      "우리는 함께": { "공부합니다": 1, "놀았습니다": 1, "밥을": 1 },
      "함께 공부합니다": { "<END>": 1 }
    }
  }
}
```

## 사용 방법

준비물: **Python 3** (추가 설치 필요 없음!)

```bash
python3 1.train/train.py     # 1) 학습
python3 2.test/test.py       # 2) 문장 만들어 보기
```

## 한계 (→ 다음 버전 예고)

앞 두 단어 문맥을 한 번도 못 본 경우엔 여전히 문장이 일찍 끊길 수 있어요.
다음 버전에서는 **개수를 확률로 바꾸고 온도(다양성)를 조절**하거나,
**백오프**(문맥을 짧게 줄여 다시 시도)로 이 문제를 다룰 예정이에요.

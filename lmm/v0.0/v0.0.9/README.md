# link_lmm — 나만의 작은 언어 모델 (v0.0.9)

누구나 쉽게 이해할 수 있는 **아주 기본적인** 언어 모델(LMM)이에요.
**개수 세기 시대(v0.0.x)의 마지막 버전**입니다.

## v0.0.8 → v0.0.9, 무엇이 바뀌었나요?

> **퍼플렉서티(perplexity) 평가 + 데이터 정비** — "얼마나 잘 맞히나?" 를 숫자로 재요.

### 1) 퍼플렉서티(PPL)

지금까지는 문장을 눈으로 보고 "그럴듯하네" 정도로 판단했어요.
v0.0.9 는 **하나의 숫자**로 모델의 실력을 잽니다.

- 각 토큰의 확률 `p` 를 구해서 → **PPL = exp( 평균( -log p ) )**
- **낮을수록 좋아요.** (1이면 완벽, 클수록 헷갈림)
- 직관: *"다음 토큰을 정할 때 평균 몇 개 중에서 헷갈리나."* PPL=5 면 5개 중 하나 고르는 수준.

### 2) 데이터 정비 (학습 / 검증 분리)

`1.data/` 를 두 개로 나눴어요.

- `data.txt` — **학습용** (모델이 외우는 것)
- `valid.txt` — **검증용** (학습에 없는 '처음 보는' 대화)

두 곳의 PPL 을 비교하면 모델이 **외우기만 하는지, 일반화하는지** 알 수 있어요.

## 실행 결과 (예시)

```bash
python3 3.train/train.py     # 학습 (data.txt)
python3 4.test/test.py       # 평가 (학습 vs 검증 PPL)
```

```
학습 데이터(282문장) PPL :   2.79   ← 외운 것이라 낮음
검증 데이터(25문장)  PPL :  34.39   ← 처음 보는 것이라 높음
→ 검증이 학습보다 약 12배 높음 = '외우기 vs 일반화' 격차
```

개수 세기 모델은 **본 것만 잘 맞혀요.** 처음 보는 조합엔 약하죠(백오프·바닥값에 의존).
이 PPL 이 바로 나중에 **신경망(v0.1.x~)이 '정말 더 나은지' 비교할 기준선**이에요.

- v0.0.1 앞 1단어 → v0.0.2 앞 2단어 → v0.0.3 문장 끝 → v0.0.4 백오프
- v0.0.5 확률+온도 → v0.0.6 문장부호 → v0.0.7 top-k/top-p → v0.0.8 대화
- **v0.0.9 퍼플렉서티 평가 ← 현재 (개수 세기 시대 완성)**

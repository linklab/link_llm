# models 폴더 (v0.0.7)

학습이 끝난 **모델 파일(`model.json`)** 이 저장되는 곳이에요.
(`3.train/train.py` 를 실행하면 자동으로 만들어집니다.)

## 이 버전 모델의 특징

- **문맥 길이:** 앞 1단어 + 2단어 (`max_order = 2`, 표 `"1"`, `"2"`)
- **토크나이저:** `punct` (v0.0.6 그대로)
- **문장 끝(`<END>`):** 학습함
- **저장된 모델은 v0.0.6 과 사실상 같아요.** top-k/top-p 는 **생성(뽑기) 단계**의 기법이라
  저장되는 개수 표는 바뀌지 않아요. 달라진 건 "표에서 어떻게 뽑느냐" 입니다.

## 효과가 보이도록 손본 데이터

`"나는 오늘"` 뒤 후보를 **머리 크고 꼬리 길게** 넣었어요.

```json
{
  "max_order": 2,
  "tokenizer": "punct",
  "tables": {
    "2": {
      "나는 오늘": {
        "학교에": 5, "공원에": 3, "도서관에": 2,
        "병원에": 1, "시장에": 1, "바다에": 1, "산에": 1,
        "극장에": 1, "서점에": 1, "카페에": 1, "놀이터에": 1,
        "우체국에": 1, "박물관에": 1, "동물원에": 1, "수영장에": 1
      }
    }
  }
}
```

- top_k=3 → `학교에·공원에·도서관에` 만 후보로 남음
- top_p=0.6 → 누적확률 60%까지(머리쪽)만 후보로 남음
- 무제한 → 꼬리의 드문 장소까지 모두 후보 (다양하지만 가끔 엉뚱)

# v0.5.0~v0.5.1 데이터 내용 검토

2026-10-01, Codex가 **48개 대화·54개 assistant 응답 전체**를 읽고 검토했습니다. AI 검토이며 사람 승인이나 독립적인 품질 보증은 아닙니다. `reviews.jsonl`은 사람 검수용으로 그대로 유지합니다.

## 확인한 내용

- 요청한 형식과 개수, JSON 키와 값, 추출 대상, 계산 결과
- 원문에 없는 정보 추가 여부, 요약·문장 수정의 의미 보존
- 멀티턴에서 이전 응답 참조와 최신 정정 반영
- 정보 부족 시 추측하지 않는지, 안전한 요청을 적절히 돕는지
- 한글·이모지·공백·줄바꿈과 본문 속 역할 문자열 보존

각 예제의 검토 근거, 확인한 응답 수, 원문 해시는 `ai_quality_audit.json`에 저장했습니다. 내용이 바뀌면 배포 도구가 오래된 검토 기록을 거부합니다. 이 검사는 검토 기록과 원문의 일치 확인이며, 문장의 의미를 자동 재평가하는 도구는 아닙니다.

## 수정한 예제

| ID | 발견한 문제 | 수정 |
|---|---|---|
| sft050-020 | 버스 지연과 지각 사이의 인과관계를 원문보다 강하게 단정 | “버스가 늦게 왔고 민수는 약속에 늦었습니다.”로 사실만 연결 |
| sft050-047 | “친구에게 빌린 책”을 돌려 달라는 요청과 답변의 대여 방향 불일치 | 요청을 “친구에게 빌려준 책”으로 수정 |

변환 데이터와 감사 보고서도 다시 만들었습니다. 기존 48개 ID의 train/valid/test 배정은 유지했으며, 각 분할은 16개·8개 과제입니다. 기존 산문 데이터와 구형 SFT 4,000개는 변경하지 않았습니다.

## 용도와 한계

교육용 SFT 파이프라인 실험에 사용할 소규모 자료입니다. 학습 분할이 16개뿐이므로 일반적인 대화 능력이나 실서비스 품질을 확보했다고 볼 수 없습니다. 데이터는 공개되어 있고 AI가 작성·검토했으므로 독립적 벤치마크로 주장하지 않습니다. v0.5.0의 사람 검수 기반 학습 승인 규칙은 유지합니다.

v0.5.1 배포 묶음에는 원본·출처·AI 검토 기록·분할·템플릿·토큰열과 모델 설정을 함께 고정했습니다. 재검증:

```bash
python llm/v0.5/v0.5.1/1.train/release.py --check
```

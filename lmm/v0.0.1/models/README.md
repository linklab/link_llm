# models 폴더 (v0.0.1)

학습이 끝난 **모델 파일(`model.json`)** 이 저장되는 곳이에요.
(`train/train.py` 를 실행하면 자동으로 만들어집니다.)

## 이 버전 모델의 특징

- **문맥 길이:** 앞 **1단어** (`max_order = 1`, 표는 `"1"` 하나뿐)
- **토크나이저:** `whitespace` (띄어쓰기로 단어 나누기)
- **문장 끝(`<END>`):** 학습 안 함
- **내용:** "어떤 단어 뒤에 어떤 단어가 몇 번 나왔는지" 를 적어둔 표

## model.json 예시

```json
{
  "max_order": 1,
  "tokenizer": "whitespace",
  "tables": {
    "1": {
      "나는": { "학교에": 1, "밥을": 1, "코딩을": 1, "게임을": 1 },
      "학교에": { "갑니다": 2 }
    }
  }
}
```

`"나는"` 이라는 **한 단어** 뒤에 어떤 단어가 몇 번 나왔는지가 표에 담겨 있어요.

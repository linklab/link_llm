# link_llm — 나만의 작은 언어 모델 (v0.0.4)

누구나 쉽게 이해할 수 있는 **아주 기본적인** 언어 모델(LLM)이에요.
어려운 신경망(딥러닝) 없이, **"단어를 세는 것"** 으로 문장을 만들어 봅니다.

## v0.0.3 → v0.0.4, 무엇이 바뀌었나요?

> **백오프(backoff): 문맥이 없으면 2단어 → 1단어로 줄여서 다시 찾아요.**

v0.0.3 은 '앞 2단어' 표 하나만 봤어요. 그래서 그 2단어 짝을 한 번도 못 본 경우엔
문장이 뚝 끊겼죠. 특히 **단어를 1개만 입력하면 아예 시작을 못 했어요.**

v0.0.4 는 표를 **두 개** 만들어 둡니다.

| 표 | 내용 | 특징 |
|----|------|------|
| 표2 | 앞 **2단어** → 다음 단어 | 자세하지만, 못 본 경우가 많음 |
| 표1 | 앞 **1단어** → 다음 단어 | 덜 자세하지만, 웬만하면 있음 |

문장을 만들 때는 이렇게 찾아요:

```
1) 앞 2단어로 표2에서 찾기
2) 없으면 → 앞 1단어로 줄여서 표1에서 다시 찾기   ← 백오프!
3) 그래도 없으면 → 멈추기
```

### 무엇이 좋아지나

- **1단어만 입력해도 시작돼요.** (`"나는"` → `"나는 아침에 밥을 먹습니다"`)
- 처음 보는 2단어 짝을 만나도 **1단어로 줄여 문장을 이어갈 수 있어요.**

이 버전은 여전히 '가장 많이 나온 단어'를 고릅니다. (확률/온도는 v0.0.5에서!)

## 저장되는 모델 형식 (v0.0.4)

표가 여러 개라서 `tables` 로 묶어 저장해요.

```json
{
  "max_order": 2,
  "tokenizer": "whitespace",
  "tables": {
    "2": { "우리는 함께": { "공부합니다": 1 }, "함께 공부합니다": { "<END>": 1 } },
    "1": { "우리는": { "함께": 2, "방학에": 2 }, "공부합니다": { "<END>": 1 } }
  }
}
```

## 사용 방법

```bash
python3 3.train/train.py     # 1) 학습 (표1, 표2 를 함께 만듦)
python3 4.test/test.py       # 2) 1단어/2단어 시작으로 문장 만들어 보기
```

## 버전

- **v0.0.1** — 앞 단어 1개로 예측
- **v0.0.2** — 앞 단어 2개로 예측
- **v0.0.3** — 문장 끝(`<END>`) 학습
- **v0.0.4** — 백오프(2→1단어 축소 재시도) ← 현재
- **v0.0.5** — 개수 → 확률 + 온도(다양성) (예정)
- **v0.0.6** — 문장부호 토크나이저 (예정)

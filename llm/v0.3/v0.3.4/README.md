# v0.3.4 — 다층 미니 GPT

## 한 줄 요약

> 독립적인 Transformer 블록을 N층 쌓아 문맥 표현을 반복해서 갱신하는 decoder-only 언어 모델입니다.

## 왜 필요한가?

- 한 블록의 출력이 다음 블록의 입력이 되어 여러 단계로 정보를 가공합니다.
- 예를 들어 ‘오늘은 비가 와서 우산을’의 다음 단어를 예측할 때 각 층이 앞선 층의 문맥 표현을 다시 활용합니다. 특정 층이 특정 언어 기능을 담당한다고 보장하지는 않습니다.
- 깊이가 증가할 때 잔차 분기의 초기 출력 규모를 줄이기 위해 scaled 초기화를 적용합니다.

## 무엇이 바뀌었나?

- 기본 4층, `--layers N`으로 변경합니다. 각 층은 별도 가중치를 가지며 공유하지 않습니다.
- 모든 블록 뒤에 최종 LayerNorm을 추가합니다.
- Linear·Embedding 가중치: 평균 0, 표준편차 0.02의 정규분포. bias는 0, LayerNorm weight는 1입니다.
- 각 블록의 어텐션 출력 projection과 FFN 마지막 projection은 표준편차 `0.02 / sqrt(2*N)`으로 초기화합니다. N=4이면 약 0.00707입니다. 학습 중 출력을 매번 나누는 방식이 아닙니다.
- 층 수·헤드 수·FFN 폭·dropout·임베딩 차원·문맥 길이를 체크포인트에 저장하고 로드 시 복원합니다.

## 모델 내부 구조

```text
입력 토큰 (B,T)
 → 토큰 임베딩 + 학습형 위치 임베딩
 → N개의 독립적인 Pre-LN 블록:
     h = h + Dropout(CausalAttention(LayerNorm(h)))
     h = h + Dropout(FFN(LayerNorm(h)))
 → 최종 LayerNorm
 → 어휘 출력층 → logits (B,T,V)
```

- encoder나 cross-attention이 없고 각 위치는 자신과 과거만 참조합니다.
- 각 잔차 단계의 PAD 표현을 0으로 유지하며 PAD는 출력 후보에서 제외합니다.
- 기본 문맥 32, 임베딩 64, 4헤드, FFN 256, dropout 0.1, Adam 0.003, 배치 64, 최대 60에폭, patience 10, 시드 1234입니다.
- 긴 입력은 최근 32토큰으로 생성하며 각 창의 위치 번호를 0부터 다시 부여합니다. END가 나오면 종료합니다.

## 효과

기본 설정 CPU 실측: **317,833개 파라미터**, 검증 **PPL 3.0463**, **top-1 75.17%**, top-5 82.45%, coverage 95.53%입니다. 검증 채점 10,197자리, epoch 8 가중치를 채택하고 epoch 18에서 조기종료했습니다. 학습·평가 약 100초가 걸렸습니다.

- 16개 CPU 테스트에서 미래 누출 방지, PAD 안전성, 모든 층의 gradient, 정답 이동, 작은 배치 과적합, 최저 검증 가중치 복원, 저장/로드 logits 완전 일치 등을 확인합니다.
- 기본값과 다른 2층·2헤드·FFN 24·dropout 0.5도 저장·복원합니다.
- 깊이에 따른 초기화 분포와 독립적인 블록 가중치를 검증합니다.
- 실측 결과·데이터 해시·환경·에폭별 기록은 `0.model/training_report.json`에 저장됩니다.

## 한계

- GPT-2식 초기화와 decoder 구조를 학습하는 소형 모델이며 GPT-2 전체 구현이나 ChatGPT 수준의 대화 모델이 아닙니다.
- 입출력 weight tying, BPE, KV 캐시, optimizer/RNG를 포함한 학습 재개는 이후 단계입니다.
- 깊이·최종 정규화·초기화를 함께 바꾸므로 성능 차이를 층 수만의 효과로 해석할 수 없습니다. 공정 비교는 v0.3.5에서 다룹니다.
- 검증 데이터는 모델 선택에 사용합니다. 단일 시드 결과이며 별도 최종 테스트 성능이 아닙니다.
- OOV를 포함한 평가 문맥/정답은 기존 FLOOR=1e-4 규칙을 따르며 현재 생성 문맥의 OOV에서는 생성을 중단합니다.

## 실행 방법

```bash
python llm/v0.3/v0.3.4/2.test/test_invariants.py
python llm/v0.3/v0.3.4/1.train/train.py --device cpu --layers 4
python llm/v0.3/v0.3.4/2.test/test.py --prompt "오늘은"
python web_service/server.py
```

PyTorch가 설치된 Python을 사용합니다. 학습 모델이 존재하면 웹앱에서 v0.3.4를 자동 검색합니다.

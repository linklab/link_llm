# models 폴더 (v0.0.6)

학습이 끝난 **모델 파일(`model.json`)** 이 저장되는 곳이에요.
(`train/train.py` 를 실행하면 자동으로 만들어집니다.)

## 이 버전 모델의 특징

- **문맥 길이:** 앞 1단어 + 2단어 (`max_order = 2`, 표 `"1"`, `"2"`)
- **토크나이저:** **`punct`** ← v0.0.5 와의 핵심 차이! (문장부호를 따로 떼어냄)
- **문장 끝(`<END>`):** 학습함
- **v0.0.5 와 차이:** `.` `,` `!` `?` 가 **하나의 토큰**으로 표에 등장해요.
  그래서 `"좋아"` 와 `"좋아!"` 를 같은 단어로 다루고, 문장부호가 언제 나오는지도 배웁니다.

## model.json 예시

```json
{
  "max_order": 2,
  "tokenizer": "punct",
  "tables": {
    "2": { "좋아합니다 !": { "<END>": 5 } },
    "1": {
      "나는": { "아침에": 7, "저녁에": 4, "코딩을": 1 },
      "!": { "<END>": 15 },
      "?": { "<END>": 11 }
    }
  }
}
```

`"!"` 나 `"?"` 뒤에는 거의 항상 `"<END>"` 가 오죠 — 문장부호가 문장을 끝맺는 신호라는 걸
모델이 배운 거예요. 그래서 생성 결과도 `오늘 날씨가 좋습니다!` 처럼 문장부호로 자연스럽게 끝나요.

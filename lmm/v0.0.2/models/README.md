# models 폴더 (v0.0.2)

학습이 끝난 **모델 파일(`model.json`)** 이 저장되는 곳이에요.
(`train/train.py` 를 실행하면 자동으로 만들어집니다.)

## 이 버전 모델의 특징

- **문맥 길이:** 앞 **2단어** (`max_order = 2`, 표는 `"2"` 하나뿐)
- **토크나이저:** `whitespace`
- **문장 끝(`<END>`):** 학습 안 함
- **v0.0.1 과 차이:** 열쇠(key)가 *한 단어* → **두 단어 짝** 으로 넓어졌어요.

## model.json 예시

```json
{
  "max_order": 2,
  "tokenizer": "whitespace",
  "tables": {
    "2": {
      "나는 아침에": { "밥을": 1, "우유를": 1, "학교에": 1 },
      "아침에 밥을": { "먹습니다": 1 }
    }
  }
}
```

`"나는 아침에"` 처럼 **두 단어** 뒤에 무엇이 나왔는지를 세기 때문에 문맥이 더 정확해요.
대신 표에 없는 두 단어 짝을 만나면 이어가기 어려워요. (→ v0.0.4 백오프에서 해결)

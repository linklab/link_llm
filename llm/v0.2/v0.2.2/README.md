# link_llm — 나만의 작은 언어 모델 (v0.2.2)

**초기화 · 정규화.** 깊은 모델을 안정적으로 학습하는 **표준 도구 세트**를 갖춥니다.
모델 구조·용량·문맥은 v0.2.1(N=3) 그대로예요.

## 한 걸음 — 도구를 얹기

| | v0.2.1 | v0.2.2 |
|---|---|---|
| 초기화 | 기본(default) | **Kaiming/Xavier** (tanh 이득 반영) |
| 정규화 | `weight_decay` 0 | **`weight_decay` 1e-4** |
| BatchNorm | 없음 | **토글 `USE_BN`** (기본 False) |
| 조기 종료 | 검증 PPL 최저 복원 | 동일 (patience=20) |
| 용량 · 문맥 | E=32 · H=128 · N=3 | **동일** |

## 구조

```
(앞 N토큰) → 임베딩 concat(N·E) → fc1 → [BatchNorm(선택)] → tanh → fc2 → logits(V)
```

- 새로 정의: `build_net` · `init_model` · `load`
- 그대로 상속: 임베딩 · 문맥(`block_size`) · 데이터 · 옵티마이저 · 조기 종료

## 성적 — 이득이 없습니다 (정직한 결과)

| 버전 | 설정 | 검증 PPL |
|---|---|---|
| v0.2.1 | N=3, 기본 | **2.37** |
| **v0.2.2** | N=3, Kaiming + wd + BN 토글 | **2.65** |

- 용량·문맥이 같으므로 이 차이는 **순수하게 초기화·정규화의 효과**예요 — 0.09 차이는 사실상 없는 것과 같습니다.
- 이유: 조기 종료가 이미 과적합을 막고 있고, 데이터가 쉽고 작아 **더 얹을 게 없어요**.
- **BatchNorm 은 여기선 손해** — 배치 통계가 노이즈로 작용합니다. 그래서 기본값 `USE_BN=False`.
  `USE_BN=True` 로 바꿔 직접 확인해 보세요.

> 💡 **교훈: 모든 기법이 모든 규모에서 통하진 않아요.**
> 이 도구들의 진가는 **깊고 큰 모델**(v0.3 트랜스포머 · v0.4 스케일업)에서 드러납니다.
> 이 버전의 값어치는 순위가 아니라 **도구를 갖춰 둔 것**이에요.

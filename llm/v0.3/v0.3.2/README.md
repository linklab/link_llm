# v0.3.2 — 학습형 위치 임베딩

## 한 줄 요약

> 토큰의 의미 벡터에 ‘현재 문맥창의 몇 번째 자리인가’를 나타내는 학습 가능한 벡터를 더합니다.

## 왜 필요한가?

- v0.3.1은 위치 벡터가 없으므로 같은 마지막 토큰 앞의 토큰 순서만 바꾸면 마지막 위치의 가중합은 순서 정보를 구분하기 어렵습니다.
- 예를 들어 `a b c`와 `b a c`의 마지막 `c`는 과거 토큰의 종류는 같지만 순서는 다릅니다. 위치 벡터를 더하면 이 차이를 표현할 수 있습니다. 실제 문장 이해 능력은 데이터와 학습으로 따로 평가해야 합니다.

## 무엇이 바뀌었나?

- `nn.Embedding(BLOCK_SIZE, EMBED)` 위치 표를 추가했습니다. 나머지 4헤드 어텐션·projection·어휘 출력은 v0.3.1과 같습니다.
- 토큰 ID가 같아도 위치가 다르면 입력 표현이 달라집니다.
- 위치 번호는 **각 슬라이딩 문맥창의 0부터 T-1**입니다. 생성·학습·배치 평가에서 같은 규칙을 사용합니다.
- PAD에는 위치 벡터를 포함한 표현을 0으로 만들고, 어텐션 key와 손실에서 계속 제외합니다.
- 위치 표보다 긴 시퀀스를 신경망에 직접 전달하면 오류를 냅니다. 공개 생성·평가 API는 최근 BLOCK_SIZE 토큰으로 창을 이동합니다.

## 모델 내부 구조

```text
token_embedding[token] + position_embedding[0..T-1]
 → multi-head causal attention (4 heads)
 → concat + output projection
 → vocabulary logits
```

기본 문맥 32·임베딩 64·4헤드입니다. v0.3.1 대비 `32×64=2,048`개 파라미터가 추가됩니다.
Adam·학습률 0.003·배치 64·최대 60에폭·검증 patience 10·시드 1234를 유지합니다.

## 효과와 검증

기본 설정 CPU 실측: **135,177개 파라미터**, 검증 **PPL 3.2066**, **top-1 74.64%**.
검증 최저 epoch 14을 채택하고 24에폭에서 조기종료했습니다. 채점 10,197자리, coverage 95.53%입니다.

- 12개 CPU 테스트: 기존 시퀀스/인과/PAD/저장/과적합/조기종료 검증 11개와 위치 검증.
- 같은 마지막 토큰을 두고 앞 토큰 순서를 바꾸면 logits를 구분할 수 있는지 확인합니다.
- 길이 1과 최대 문맥 길이, 길이 0과 초과 입력 거부, 위치 표 gradient를 검증합니다.
- 배치 PPL과 개별 token_prob의 일치 테스트에는 문맥창보다 긴 문장과 OOV도 포함됩니다.
- 실측 데이터 해시·설정·환경·결과는 `0.model/training_report.json`에 저장합니다.

## 한계

- 위치 표현을 추가했다고 순서 이해가 완성되는 것은 아닙니다. 여기의 순서 테스트는 표현 가능성 검증이며 의미 이해 벤치마크가 아닙니다.
- 위치 표는 유한하며 장거리 외삽을 지원하지 않습니다. RoPE는 후속 심화 계획입니다.
- 잔차 연결·LayerNorm·FFN은 아직 없으며 v0.3.3에서 추가합니다.
- 기존 합성 산문과 검증 PPL을 사용합니다. OOV/FLOOR 처리, 긴 문장 슬라이딩 비용, 최종 테스트 부재와 산문 대화 한계는 v0.3.0과 같습니다.

## 실행·코드

```bash
python llm/v0.3/v0.3.2/2.test/test_invariants.py
python llm/v0.3/v0.3.2/1.train/train.py --device cpu
python llm/v0.3/v0.3.2/2.test/test.py --prompt "오늘은"
python web_service/server.py
```

PyTorch가 설치된 Python을 사용합니다. `network.py`는 v0.3.1의 입력 임베딩만 확장하고,
`lm.py`는 해당 신경망과 모델 버전을 지정합니다. 이전 데이터·학습·평가 코드와 heads 메타데이터를 상속합니다.
가중치는 Git 제외 대상이므로 다른 컴퓨터에서는 재학습 또는 모델 파일 전달이 필요합니다.
